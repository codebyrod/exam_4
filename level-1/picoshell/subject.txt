Write the following function:

int    picoshell(char **cmds[]);

The goal of this function is to execute a pipeline. It must execute each
commands of cmds and connect the output of one to the input of the

Cmds contains a null-terminated list of valid commands. Each rows

## Português

Nome do exercício:	picoshell
Arquivos esperados:	picoshell.c
Funções permitidas:	close, fork, wait, exit, execvp, dup2, pipe
___________________________________________________________________

Implemente a seguinte função:

int    picoshell(char **cmds[]);

O objetivo desta função é executar um *pipeline*. Ela deve executar cada um dos comandos contidos em `cmds` e conectar a saída de um comando à entrada do próximo (assim como um *shell* faria). `cmds` consiste em uma lista de comandos válidos, terminada por um valor nulo (*null-terminated*). Cada elemento de `cmds` é um *array* do tipo `argv`, pronto para ser utilizado em uma chamada à função `execvp`. O primeiro argumento de cada comando — que pode ser o nome do comando ou seu caminho (*path*) — pode ser passado diretamente como o primeiro argumento de `execvp`.

Caso ocorra algum erro, a função deve retornar 1 (lembrando que, antes disso, todos os descritores de arquivo (*file descriptors* — FDs) abertos devem ser fechados). Caso contrário, a função deve aguardar a finalização de todos os processos filhos e retornar 0. Neste diretório, você encontrará um arquivo chamado `main.c`, que contém um código auxiliar para testar sua função.

Exemplos:
./picoshell /bin/ls "|" /usr/bin/grep picoshell
picoshell
./picoshell echo 'squalala' "|" cat "|" sed 's/a/b/g'
squblblb

Resumo elaborado por um aluno:
É fornecida uma função `main` que converte os argumentos recebidos em um *array* de *arrays* de *strings* (`cmds`). Quando há um *pipe*, os comandos que aparecem após o *pipe* são organizados no próximo *array* de *strings*. Você deve criar um *pipeline* utilizando os comandos recebidos via `cmds` e executá-los. Se ocorrer qualquer erro, a função deve retornar 1 — lembrando-se de fechar todos os descritores de arquivo (*FDs*) antes de retornar. Se os comandos forem executados com sucesso, aguarde a finalização de todos os processos filhos e retorne 0.
